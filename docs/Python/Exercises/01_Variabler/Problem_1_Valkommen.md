# Välkommen
Variabler, övning 1

## Uppgift

Skriv ett program som frågar efter användarens namn och sedan hälsar på personen.

### Indata

Användaren skriver in sitt namn.

### Utdata

Skriv ut `Hej, NAMN!`, där NAMN ersätts med det inmatade namnet.

### Exempel

**Input**

```text
Alve
```

**Output**

```text
Hej, Alve!
```

### Förklaring

Använd `input()` för att läsa in namnet. Spara svaret i en variabel och använd `print()` för att skriva ut hälsningen.
