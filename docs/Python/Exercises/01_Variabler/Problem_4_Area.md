# Area
Variabler, övning 4

## Uppgift

Skriv ett program som beräknar arean av en rektangel.

### Indata

Första raden tar emot bredd som decimaltal.Andra raden tar emot höjd som ett decimaltal Indata använder punkt som decimaltecken.

### Utdata

Skriv ut rektangelns area.

### Exempel

**Input**

```text
3.5
2
```

**Output**

```text
7.0
```

### Förklaring

Arean beräknas genom att multiplicera bredden med höjden. Läs in värdena med `float()` så att programmet kan hantera decimaltal. Formeln är `area = bredd * höjd`. 

Exempel:
```python
width = float(input("Type width: "))
```
