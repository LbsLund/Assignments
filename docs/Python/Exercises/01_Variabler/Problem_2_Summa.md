# Summan
Variabler, övning 2

## Uppgift

Skriv ett program som läser in två heltal och skriver ut summan av de två.

### Indata

Två rader. Varje rad innehåller ett heltal.

### Utdata

Skriv ut summan av talen.

### Exempel

**Input**

```text
7
5
```

**Output**

```text
12
```

### Förklaring

Läs in båda värdena med `input()`. Eftersom `input()` ger text behöver du omvandla värdena till heltal med `int()` innan du adderar dem. Spara talen i två variabler.

Exempel:
```python
firstNumber = int(input("Type first number: "))
```
