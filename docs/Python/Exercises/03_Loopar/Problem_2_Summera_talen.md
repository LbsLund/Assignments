# Summera talen
Loopar, övning 2

## Uppgift

Skriv ett program som läser in ett positivt heltal N och beräknar summan av alla heltal från 1 till och med N.

### Indata

Ett positivt heltal N.

### Utdata

Skriv ut summan.

### Exempel

**Input**

```text
4
```

**Output**

```text
10
```

### Förklaring

Summan blir `1 + 2 + 3 + 4 = 10`. Skapa en heltals-variabel som börjar på 0. Gå igenom talen från 1 till N och lägg till varje tal till summan. Skriv ut summan när loopen är klar.
