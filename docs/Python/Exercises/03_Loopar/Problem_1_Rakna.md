# Räkna
Loopar, övning 1

## Uppgift

Skriv ett program som läser in ett positivt heltal N och skriver ut alla heltal från 1 till och med N, ett tal per rad.

### Indata

Ett positivt heltal N.

### Utdata

Skriv ut talen från 1 till N, ett tal per rad.

### Exempel

**Input**

```text
5
```

**Output**

```text
1
2
3
4
5
```

### Förklaring

Använd en for-loop som börjar vid 1 och fortsätter till och med N. Med `range()` kan du använda `range(1, n + 1)`, eftersom slutvärdet i `range()` inte ingår.
