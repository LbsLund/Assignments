# Multiplikation
Loopar, övning 3

## Uppgift

Skriv ett program som läser in ett heltal och skriver ut dess multiplikationstabell från 1 till 10.

### Indata

Ett heltal.

### Utdata

Skriv ut tio rader i formatet `tal x faktor = produkt`.

### Exempel

**Input**

```text
3
```

**Output**

```text
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
```

### Förklaring

Använd en loop där faktorn går från 1 till 10. I varje varv multiplicerar du det inlästa talet med faktorn. Konvertera heltalen till string-data för utskriften.
