# Minsta
Datastrukturer, övning 3

## Uppgift

Skriv ett program som läser in N heltal och skriver ut det största talet.

### Indata

Första raden består av heltal separerade med mellanrum.

### Utdata

Skriv ut det minsta talet.

### Exempel

**Input**

```text
4 12 -3 8 7
```

**Output**

```text
-3
```

### Förklaring

Spara talen i en lista. Skapa en heltals-variabel som får värdet av första elementet i listan. Gå igenom talen i listan och ändra variabeln om ett mindre tal hittas. Skriv sedan ut variabeln.
