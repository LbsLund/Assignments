# Algoritmer 3

## Hur många?

Du får en lista med heltal och ett tal `x`.

Din uppgift är att räkna hur många gånger `x` förekommer i listan.

För att lösa problemet kan du gå igenom listan ett tal i taget. Varje
gång du hittar `x` ökar du en räknare med ett.

### Indata

Den första raden innehåller ett heltal `n`, antalet tal.

Den andra raden innehåller `n` heltal.

Den tredje raden innehåller heltalet `x`.

### Utdata

Skriv ut hur många gånger `x` förekommer i listan.

### Exempel

**Input**

``` text
7
2 5 2 8 2 3 5
2
```

**Output**

``` text
3
```

### Förklaring

Talet `2` finns på tre platser i listan.
