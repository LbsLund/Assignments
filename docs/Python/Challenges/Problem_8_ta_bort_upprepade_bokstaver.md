# Problem 8

## Ta bort upprepade bokstäver

Skapa en ny text där varje sammanhängande följd av samma bokstav ersätts med en enda bokstav. Bara upprepningar direkt efter varandra tas bort.

### Indata

Ta emot en textrad.

### Utdata

Skriv ut den nya texten.

### Exempel

**Input**

```text
aaabbccccdaa
```

**Output**

```text
abcda
```

### Förklaring

Gå igenom texten och lägg bara till ett tecken om det skiljer sig från det senast tillagda tecknet.
