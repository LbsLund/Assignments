# Problem 6

## Räkna ett ord

Du får en rad med ord och därefter ett sökord. Räkna hur många gånger sökordet förekommer. Stora och små bokstäver ska behandlas likadant.

### Indata

Första raden innehåller ord separerade av mellanslag. Andra raden innehåller sökordet.

### Utdata

Skriv ut antalet förekomster.

### Exempel

**Input**

```text
Katt hund katt fågel katt
katt
```

**Output**

```text
3
```

### Förklaring

Spara orden som en lista och kolla hur många gånger sökordet förekommer i listan.
